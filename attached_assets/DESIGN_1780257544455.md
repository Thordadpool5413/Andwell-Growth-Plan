## Brand & Style

The design system is engineered for healthcare executives and clinical leaders, prioritizing **Clinical Precision** and **Empirical Transparency**. The brand personality is authoritative, analytical, and high-telemetry, transforming dense regulatory CMS data into actionable executive strategies.

The visual style is a hybrid of **Minimalist Modernism** and **Glassmorphism**, now optimized for a high-clarity **Light Mode** environment. This "Executive Briefing" atmosphere emphasizes professional transparency, clarity of data, and modern analytical control.

The interface relies on high-density information layouts, crisp boundaries, and sophisticated data provenance indicators to maintain a "clinical-grade" feel.

## Colors

The color palette is strictly functional, mapping specifically to data provenance and cognitive layers in a light, high-clarity environment:
- **Primary (Vibrant Azure):** (#346ef6) Core identity and interaction. Used for active navigation and priority highlights.
- **Secondary (Muted Steel-Blue):** (#6275af) Exclusively reserved for the **AI Co-pilot** and cognitive assistive layers.
- **Tertiary (Burnt Ochre):** (#bc4800) Represents critical regulatory alerts or high-priority CMS metrics.
- **Neutral (Slate Grey):** (#757681) Used for structural elements and secondary labels.

**Surface Tones:**
- **Light Mode (Default):** Background `Surface` (#f9f9ff), with elevated containers using `Surface-Container` variants.
- **Visual Depth:** Semi-translucent layers are used to distinguish analytical modules from the base canvas, utilizing high-opacity white fills to maintain readability.

## Typography

This system is anchored entirely by **Inter** to ensure maximum legibility for dense numerical grids and administrative data. 

**Key Rules:**
- **Headings:** Utilize `font-black` (900) with negative tracking to project density and executive authority.
- **Eyebrows:** Use micro-sized, uppercase text with extreme letter spacing (0.3em) to structure page sections without adding visual weight.
- **Data Visualization:** Numerical metrics must use the `metric-value` style to ensure they are the most prominent elements on the canvas.
- **Footnotes:** Use the `footnote` style for all data sourcing (e.g., "Source: CMS 2022 PUF") to maintain clinical rigor without distracting from primary insights.

## Layout & Spacing

The design system follows a strict **4px base unit** layout rhythm.

**Grid Philosophy:**
- **Structure:** Uses a **Fixed Grid** model within an authoritative `1280px` max-width container. 
- **Telemetry Blocks:** Stat cards are organized in a responsive 4-column grid (`grid-cols-1 md:grid-cols-4`).
- **Vertical Rhythm:** Main sections are separated by a standard `32px` (xl) or `24px` (lg) gap to ensure clarity between analytical modules.
- **Responsive Handling:** On mobile, margins reduce to `16px`, and data tables utilize horizontal overflow containers to preserve column integrity for clinical metrics.

## Elevation & Depth

Hierarchy is established through **Tonal Layering** and **Glassmorphism**:

- **Surfaces:** Cards use a high-radius container with a subtle `1px` border (Neutral-200/300).
- **Depth:** Soft, diffused shadows are used sparingly to indicate modularity. For the Light Canvas, surfaces employ `backdrop-blur` and semi-translucent fills (90-98% opacity) to simulate an advanced analytical interface.
- **Interaction:** Metric cards should "lift" on hover (`translate-y-[-2px]`) with a slight shadow increase to signal interactivity.
- **AI Layer:** The AI Co-pilot drawer utilizes a `z-50` elevation with a heavy shadow and a soft secondary glow (#6275af) to distinguish it from standard data modules.

## Shapes

The design system utilizes an **Aggressive Roundedness** strategy to soften the density of clinical data:

- **Primary Containers:** Sections and Main Cards use `rounded-3xl` (2rem) to create distinct, modern clusters of information.
- **Interactive Elements:** Buttons and active tab indicators use `rounded-full` (pill-shaped) to clearly distinguish them from static data containers.
- **Data Accents:** Small badges and input fields use `rounded-lg` or `rounded-md` to maintain precision at smaller scales.

## Components

### Buttons
- **Primary:** Pill-shaped (`rounded-full`), `font-black` (900) text. Uses Primary Azure (#346ef6).
- **Interaction:** High-contrast backgrounds with subtle scaling effects on hover.

### Analytical Cards
- **Structure:** `rounded-3xl` with `1px` borders and backdrop-blur.
- **Accents:** Optional `border-t-2` or `border-l-4` using functional colors to denote data status or service line themes.

### Status Badges (Provenance)
- **CMS Verified:** Primary-toned subtle backgrounds with high-contrast text.
- **Estimated (EstBadge):** Dotted underline chip with `cursor-help`, using neutral-grey tones.

### Segmented Tabs
- Wrapped in a `rounded-2xl` container. Active states feature a background shift and a `2px` bottom rail in the primary azure color.

### AI Co-Pilot (Drawer)
- Floating action button at `bottom-6 right-6`.
- Features diagnostic "bouncing" loaders in Secondary-toned steel-blue (#6275af) and suggested prompt chips using the `rounded-full` shape language.

### Form Inputs & Sliders
- **Executive Sliders:** Thin rails (`h-2`) with high-contrast Primary-500 thumbs, designed for scenario modeling and "what-if" calculations.
